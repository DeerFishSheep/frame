## 数据与缓存的实际边界

- 预览固定 16 部样本；搜索和筛选只针对这些样本。评分、票数、热度为未提供状态。
- 当前本地真实接口已返回 HTTP 200、`source: tmdb`；凭证仅在被忽略的 `.env.local` 中维护。
- 支持 `TMDB_API_KEY` 或 `TMDB_API_READ_ACCESS_TOKEN`，同时存在时优先 Token；日志和提交不得记录真实值。
- 缓存是请求触发的进程内缓存，默认 TTL 1800 秒；到期后的下一次请求尝试刷新。
- 已实现并发去重、超时／429／短暂网络失败重试及旧缓存回退；这些通过模拟返回验证。
- 尚未实现 Cron 定时预取、持久缓存、数据库或历史榜单快照。
- 猜你喜欢使用 `recommendations`，保留整页与分页元数据；滑到末尾加载下一页，失败可重试，按复合 ID 去重。沿用 TMDB 最多 500 页边界；未把独立 `similar` 标为完成。
- 测试中的 `test-token` 和 fake fetch 不证明真实凭证、网络或上游数据已经可用。
